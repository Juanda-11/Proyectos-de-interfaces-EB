# Contribuir

1. Crea una rama desde `main` (`feat/...`, `fix/...`, `docs/...`).
2. Usa [Conventional Commits](https://www.conventionalcommits.org/es/) en los mensajes (`feat(simulación): ...`).
3. Antes de abrir el pull request ejecuta `npm run lint && npm run format:check && npm test`.
4. Si cambias la API, actualiza `docs/openapi.yaml` y el README.
